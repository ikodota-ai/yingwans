# Kemovie 前台视觉设计规范与线框

> 面向内地用户的私人影库 + 上线订阅提醒工具。前台为 C 端影迷产品，技术栈锁定 Vue2 + Element UI，本规范在其基础上做深色定制。后台管理沿用 RuoYi 默认风格，不在本规范内。

## 1. 设计语言

- **定位**：电影感、沉浸、克制。海报是第一视觉主角，UI 退居辅助。
- **基调**：深色影院背景，暖金色点缀（区别于 Letterboxd 的绿、JustWatch 的黄）。
- **原则**：
  - 海报优先：列表以海报墙为主，文字信息弱化。
  - 少即是美：无评论/影评区，页面聚焦「发现 → 收藏 → 追踪」。
  - 一致的圆角与留白，避免后台管理系统的密集表格感。

## 2. 配色系统（CSS 变量）

```css
:root {
  /* 背景层次（越靠上越亮） */
  --bg-base:      #0d0e12;  /* 页面底 */
  --bg-surface:   #16181f;  /* 卡片 */
  --bg-elevated:  #1f232d;  /* 弹层/悬浮 */
  --border:       #2a2e39;

  /* 文字 */
  --text-primary:   #f5f6f8;
  --text-secondary: #9aa0ac;
  --text-muted:     #6b7280;

  /* 品牌与强调 */
  --brand:        #e8b84b;  /* 暖金：主按钮、评分星、logo */
  --brand-hover:  #f2c85f;
  --accent:       #4f9dff;  /* 链接、次要交互 */

  /* 状态语义 */
  --success: #3fb984;  /* 已上线 */
  --warning: #e8a13a;  /* 即将上线 */
  --danger:  #e5484d;  /* 下架/失效 */
  --wish:    #c07be0;  /* 想看 */
}
```

- **评分色阶**：0–4 红、4–7 黄、7–10 绿，用于站内评分与 TMDB 分展示。
- **平台标识**：Netflix/Disney+/爱奇艺等用官方 logo 原色小图标，不重绘。

## 3. 字体与排版

- **字体栈**：`"PingFang SC", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`；数字/评分用 `"DIN", "Roboto"` 增强质感。
- **字号阶梯**：标题 28 / 页面区块 20 / 卡片标题 15 / 正文 14 / 辅助 12。
- **行高**：正文 1.6，标题 1.3。
- **字重**：标题 600，正文 400，强调数字 700。

## 4. 间距与圆角

- **间距基数** 4px：常用 8 / 12 / 16 / 24 / 32。
- **圆角**：卡片 10px，海报 8px，按钮 8px，标签 4px，头像/圆钮全圆。
- **栅格**：桌面 12 栏，内容最大宽 1200px；海报墙响应式 6/4/3/2 列（桌面/平板横/平板竖/手机）。
- **阴影**：仅悬浮态用 `0 8px 24px rgba(0,0,0,.4)`，静态卡片不投影，靠背景层次区分。

## 5. 核心组件规范

- **PosterCard（海报卡）**：2:3 海报 + 底部渐变遮罩显示片名/年份；悬浮浮起 4px 并显现快捷操作（想看♡ / 已看✓ / 订阅🔔）。
- **RatingStars**：暖金五星，支持半星；只读态与可评态两种。
- **ActionBar（详情页行为条）**：点赞、想看、看过、评分、订阅五个动作，按钮态区分「已激活/未激活」。
- **PlatformBadge**：平台 logo + 上线日期 + offer 类型（会员/租/购）标签。
- **RailSection（横向滑轨）**：首页「热门」「新上线」「片单精选」用横向滚动 rail，标题右侧「查看全部」。
- **CollectionCard（片单卡）**：4 张海报拼贴封面 + 片单名 + 影片数 + 来源标签（系统/用户/TMDB/MDL）。
- **EmptyState / SkeletonLoader**：海报墙加载用骨架屏，避免闪烁；空态配插画文案。

## 6. 信息架构（前台导航）

```
顶部导航：Logo | 发现 | 片单 | 我的片库 | 订阅提醒(🔔角标) | 搜索 | 头像菜单
```

- **发现 Discover**：首页，热门榜 + 新上线 + 分类浏览。
- **片单 Collections**：系统自动片单（TMDB/MDL 抓取生成）+ 公开的用户片单。
- **我的片库 My Library**：想看 / 看过 / 我的评分 / 我创建的片单，Tab 切换。
- **订阅提醒 Subscriptions**：我订阅的影片 + 上线时间轴 + 通知记录。
- **影片详情 Media Detail**：单片全信息页。

## 8. 交互与状态

- **行为反馈**：点赞/想看/看过点击即时高亮 + 轻微缩放动画，乐观更新。
- **评分**：星条 hover 预览，点击落分，可清除。
- **订阅**：订阅后铃铛填充 + 顶部导航角标 +1。
- **加载**：海报墙骨架屏；rail 左右滑动惯性。
- **图片容错**：`poster_local_url` 优先，失败回退 TMDB 原图，再回退占位图（避免内地图源慢导致空白）。
- **响应式**：手机端底部 Tab 栏替代顶部导航，海报墙降为 2 列。

## 9. 与后端字段的对应（供开发对齐）

- 海报：`km_media.poster_local_url` ← 优先，回退 `poster_path`（拼 `TMDB_IMAGE_BASE`）。
- 评分：站内 `km_user_media_action.rating` 聚合均分 vs `km_media.vote_average`（TMDB）分开展示。
- 上线平台：`km_media_release`（platform/offer_type/online_date）驱动详情页与订阅时间轴。
- 热门榜：`km_hot_rank` 快照直接渲染首页 rail，带 rank_no 角标。
- 片单来源标签：`km_collection.source`（system/tmdb/mdl/manual）。

## 10. 已确认决策

- **产品名**：影弯（Kemovie）。「影湾」已被注册，故用「影弯」。顶部 Logo 为「影」（暖金）+「弯」文字组合。
- **主题**：深色（默认）+ 浅色双主题，顶部导航一键切换，偏好存 `localStorage('portal-theme')`。CSS 变量集中在 `views/portal/theme.scss`，通过 `.portal-root[data-portal-theme]` 切换。
- **运营位**：详情页底部（`detail_footer`）+ 首页侧栏（`home_side`）两处，均由后台「运营位管理」配置（私域二维码等）。

## 11. 前台实现落点（开发对齐）

- 布局：`views/portal/Layout.vue`（导航 + 主题切换 + 未读角标）。
- 页面：`Discover` 发现 / `Collections` 片单 / `CollectionDetail` 片单详情 / `FilmDetail` 影片详情 / `Library` 我的片库 / `Subscriptions` 订阅提醒。
- 组件：`PosterCard` / `RatingStars` / `PlatformBadge` / `CollectionCard` / `OpsBlock`。
- 接口：`api/kemovie/portal.js`（/portal 公开）、`api/kemovie/me.js`（/me 登录）、`api/kemovie/admin.js`（/kemovie 后台）。
- 路由：`router/index.js` 常量路由挂载 `/discover /collections /collection/:id /film/:id /library /subscriptions`；`permission.js` 白名单放行公开浏览页。
